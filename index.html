여러 기기에서 같이 쓰기

GitHub 저장소에 데이터 파일 하나를 두고, 폰과 PC가 그 파일을 같이 읽고 씁니다. 처음 한 번만 각 기기에서 설정하세요.

토큰 만들기: GitHub → Settings → Developer settings → Fine-grained tokens. 이 저장소 하나만 고르고 Contents를 Read and write로 설정합니다. 토큰은 이 기기 브라우저에만 저장됩니다. 비워 두면 읽기만 됩니다.

주의: 환자 이름 등 개인정보는 적지 마세요. 공개 저장소면 데이터 파일도 공개됩니다. 비공개 저장소를 따로 만들어 데이터 파일만 두는 쪽을 권합니다.
