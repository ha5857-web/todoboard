할 일 편집

시작일과 기한을 정하면 타임라인에 막대로 보입니다. 기한만 정하면 오늘부터 기한까지 남은 시간이 점선으로 보입니다.

완료하면 다음 기한이 자동으로 잡히고, 그 날짜가 되면 다시 '할 일'로 돌아옵니다.

페이지가 열려 있으면 정한 시각에 진동과 알림 배너가 뜹니다. 폰이 잠겨 있거나 페이지를 닫아도 울리게 하려면 위 버튼으로 폰 캘린더에 등록하세요. 반복 업무는 시각만 유지되고 날짜는 다음 기한을 따라갑니다.

여러 기기에서 같이 쓰기

GitHub 저장소에 데이터 파일 하나를 두고, 폰과 PC가 그 파일을 같이 읽고 씁니다. 처음 한 번만 각 기기에서 설정하세요.

토큰 만들기: GitHub → Settings → Developer settings → Fine-grained tokens. 이 저장소 하나만 고르고 Contents를 Read and write로 설정합니다. 토큰은 이 기기 브라우저에만 저장됩니다. 비워 두면 읽기만 됩니다.

주의: 환자 이름 등 개인정보는 적지 마세요. 공개 저장소면 데이터 파일도 공개됩니다. 비공개 저장소를 따로 만들어 데이터 파일만 두는 쪽을 권합니다.

구글 캘린더 → 다른 캘린더 추가 → URL로 추가에 위 주소를 붙여넣으면, 시작일·기한이 있는 일이 종일 일정으로 보입니다. 구독한 캘린더는 읽기 전용이고 구글이 몇 시간~하루 간격으로 새로 가져옵니다. 공개 저장소면 이 파일의 내용도 공개됩니다.
